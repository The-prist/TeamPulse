## 三、连法一：脚本写入（先关 DBeaver）

DBeaver 把连接配置存在
`%APPDATA%\DBeaverData\workspace6\General\.dbeaver\data-sources.json`。

**关键：必须先完全退出 DBeaver**（含右下角托盘图标），否则它退出时会用内存里的旧配置
覆盖该文件，刚写进去的连接就没了。

```powershell
# 1. 完全退出 DBeaver
# 2. 在项目根目录执行
.\scripts\dbeaver-add-connection.ps1

# 3. 重新打开 DBeaver，左侧应出现名为 TeamPulse 的连接
# 4. 双击它 → 输入你的 MySQL 密码（可勾选「保存密码」）
```

脚本会：

- 检查 DBeaver 是否在运行（在运行就提示并退出，不冒险写入）
- **自动备份**原 `data-sources.json`（`data-sources.json.bak-时间戳`）
- 幂等：重复运行只会更新同一个连接，不会产生多条
- 把 `allowPublicKeyRetrieval=true` 写进连接串（见第五节）

> 你当前的 `data-sources.json` 是**空文件**（一个连接都没有），所以写入是安全的。
> 但如果 DBeaver 版本不认这个格式，可能不显示——那时请用下面的手动方式。

## 四、连法二：界面手动新建（最稳，60 秒）

DBeaver 是中文界面，按这个顺序点：

1. 菜单 **数据库 → 新建数据库连接**（或左上角工具栏的插头图标 ⊕）
2. 选择 **MySQL** → 下一步
3. 填连接参数：
   - 服务器地址：`127.0.0.1`
   - 端口：`3306`
   - 数据库：`teampulse`
   - 用户名：`root`
   - 密码：`<你的密码>`（勾选「保存密码」）
4. 点 **驱动属性**（Driver properties）标签页 → 找到并修改：
   - `allowPublicKeyRetrieval` → `true`
   - `useSSL` → `false`
   > 不改这两项，MySQL 8.4 大概率报 `Public Key Retrieval is not allowed`。
5. 点 **测试连接**（Test Connection）
   - 第一次会提示下载 MySQL 驱动，点「下载」，需要联网，约 10~30 秒
6. 点 **完成**

## 五、必踩坑：`Public Key Retrieval is not allowed`

**原因**：MySQL 8 起默认认证插件是 `caching_sha2_password`。密码走的是 RSA 公钥加密，
DBeaver 默认不允许客户端主动取服务端公钥，于是连接被拒。

**三种解法，任选其一**：

| 解法 | 做法 | 评价 |
|---|---|---|
| 加驱动属性（推荐） | 连接属性里设 `allowPublicKeyRetrieval=true` | 只影响这个连接，最安全 |
| 用 SSL | `useSSL=true` 并配置证书 | 本地开发没必要 |
| 改用户认证插件 | `ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '<你的密码>';` | 会降低该账号安全性，不推荐 |

脚本写入的连接已经带了第 1 种解法。

## 六、连不上时按顺序排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `Can't connect ... (10061)` | **MySQL 没启动** | 运行 `E:\dev\mysql\start-mysql.cmd` |
| `Access denied for user 'root'` | 密码不对 | 用你自己的 MySQL 密码（文档不记录真实密码） |
| `Unknown database 'teampulse'` | 库不存在 | 启动后端一次，Flyway 会自动建库建表 |
| `Public Key Retrieval is not allowed` | 认证插件问题 | 见第五节 |
| 表里中文显示成 `???` | 客户端字符集 | 连接属性加 `characterEncoding=utf8`；或 `SET NAMES utf8mb4` |
| 时间是 UTC / 差 8 小时 | 时区 | 连接属性加 `serverTimezone=Asia/Shanghai` |
| 看不到表但有库 | 没选中 schema | DBeaver 里展开连接下的 `teampulse` → `Tables` |

**检查 MySQL 是否在跑**（PowerShell）：

```powershell
Get-NetTCPConnection -LocalPort 3306 -State Listen
# 有输出 = 在跑；没输出 = 要先启动
E:\dev\mysql\start-mysql.cmd
```

**停止 MySQL**：`E:\dev\mysql\stop-mysql.cmd`

## 八、两个实用查询

**看最近一次打卡（跑过模拟器后）**

```sql
SELECT r.id, r.employee_no, u.nickname, r.punch_type, r.punch_time,
       r.status, r.late_minutes, r.early_leave_minutes, r.source
FROM attendance_record r
LEFT JOIN `user` u ON r.user_id = u.user_id
ORDER BY r.id DESC
LIMIT 20;
```

**看某人某天的考勤汇总**

```sql
SELECT work_date, first_check_in, last_check_out,
       work_minutes, late_minutes, attendance_status
FROM attendance_daily
WHERE user_id = 1
ORDER BY work_date DESC;
```

## 九、想用命令行连（不用 DBeaver）

```powershell
& 'E:\dev\mysql\bin\mysql.exe' -h 127.0.0.1 -uroot -p --default-character-set=utf8mb4 teampulse
```

> 加 `--default-character-set=utf8mb4` 是为了让 Windows 终端正确显示中文；
> 不加的话中文会变成乱码（这是终端显示问题，数据库里的数据是对的）。
